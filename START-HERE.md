## 🎯 O que é Realizah?

Plataforma híbrida que combina:
- 🛒 E-commerce de produtos físicos
- 📥 Produtos digitais (ebooks, templates)
- 🎓 Plataforma LMS (cursos online)
- 💎 Sistema de assinaturas (Free/Pro/Premium)
